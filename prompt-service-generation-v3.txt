1. META TITLE (50-60 car.) — incluant le service + ville + CP
   Exemple : "Réparation Toiture Compiègne 60200 | Artisan Qualifié"

2. META DESCRIPTION (150-160 car.) — bénéfice + urgence + ville
   Exemple : "Réparation toiture à Compiègne (60200). Intervention rapide,
   devis gratuit sous 24h. Artisan certifié RGE. ☎ Appelez maintenant !"

3. MOTS-CLÉS (15-20, séparés par virgule)
   Inclure : service + ville, service + CP, artisan + ville, urgence + service + ville

4. TITRE H1 (accrocheur, 1 ligne)

5. DESCRIPTION COURTE (120-140 car. — pour les cards)

6. CONTENU HTML COMPLET (voir structure ci-dessous)
